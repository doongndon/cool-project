# 🧑‍🦳 AI 손주 — 어르신 디지털 도우미

> **대회 주제**: 고령층의 생활 속 디지털 소외 및 정보 격차
>
> 손주가 옆에서 알려주듯, 어르신의 디지털 생활을 돕는 AI 웹앱입니다.

## 🌟 주요 기능

### 1. 📄 어려운 서류 풀이
계약서, 고지서, 보험 안내문 등을 **카메라로 찍기만 하면**:
- 초등학생도 이해할 수 있는 **쉬운 말 요약**
- 돈이 나가거나 불리할 수 있는 **"조심하세요!" 경고** (독소조항 탐지)
- 금액·날짜·기간 등 **꼭 기억할 것** 정리
- 어려운 단어 **쉬운 뜻풀이 사전**
- 🔊 **음성으로 읽어주기** (눈이 침침하셔도 OK)
- 서류에 대해 **추가 질문** 가능 (음성 입력 지원)

### 2. 📱 폰 사용법 알려줘 (화면 인식 튜토리얼)
"카카오톡으로 사진 어떻게 보내요?" 같은 질문을 **말로** 하면:
- 단계별로 아주 쉬운 안내
- **폰 화면 캡처를 올리면 AI가 화면을 직접 인식**해서
  누를 버튼에 빨간 동그라미 + 👆 **"여기를 누르세요!"** 표시
- 🔊 모든 안내를 음성으로 들려주기

### 3. ♿ 고령층 접근성 설계
- 큰 글씨 (3단계 크기 조절), 큰 버튼 (최소 56px 터치 영역)
- 높은 색 대비, 화면당 한 가지 일만 하는 단순한 구조
- 음성 입력(STT) / 음성 안내(TTS) 전면 지원
- 존댓말과 다정한 말투 — "AI 손주" 컨셉

## 🛠 기술 구성

| 구분 | 내용 |
|---|---|
| AI | Google **Gemini API (무료 등급)** — 멀티모달 (문서 OCR·이해 + 화면 인식 + 좌표 추출) |
| 프론트엔드 | 순수 HTML/CSS/JavaScript (프레임워크·빌드 도구 없음) |
| 음성 | Web Speech API (브라우저 내장 TTS/STT, 무료) |
| 서버 | **없음** — 100% 클라이언트에서 동작, 개인정보가 우리 서버에 저장되지 않음 |

화면 인식 좌표는 Gemini의 bounding box 출력(`box_2d`, 0~1000 정규화)을 이용해
Canvas 위에 스포트라이트 + 빨간 원 + 손가락 마커로 그립니다.

## 🚀 실행 방법

1. **무료 Gemini API 키 발급**: https://aistudio.google.com/apikey (구글 계정만 있으면 무료)
2. 이 저장소를 아무 정적 호스팅에 올리거나 로컬에서 실행:
   ```bash
   # 로컬 실행 (카메라 사용을 위해 localhost 또는 https 필요)
   python3 -m http.server 8000
   # 폰에서 접속하려면 같은 와이파이에서 http://<PC IP>:8000
   ```
   또는 GitHub Pages에 올리면 폰에서 바로 접속 가능합니다.
3. 앱 첫 실행 시 뜨는 설정 창에 API 키 붙여넣기 (폰에만 저장됨)
