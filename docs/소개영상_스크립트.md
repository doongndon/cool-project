# 소개영상 스크립트 (약 2분)

> 준비물: 폰 1대(앱 시연용), 계약서 아무거나 1장, 미리 찍어둔 폰 설정 화면 캡처 1장.
> 폰 화면 녹화 기능으로 찍으면 편집이 가장 쉽습니다.

---

## 장면 1 — 문제 제기 (0:00 ~ 0:25)

**[화면]** 계약서를 들고 난감해하는 모습 / 스마트폰을 들고 헤매는 모습 (사진 몇 장이어도 됨)

**[내레이션]**
"위약금, 약정 기간, 자동 갱신... 어르신들에게 계약서는 외국어나 다름없습니다.
스마트폰 설정 하나 바꾸려 해도, 어디를 눌러야 할지 몰라 매번 자녀에게 전화를 겁니다.
디지털 세상은 편리해졌지만, 우리 부모님 세대에게는 오히려 더 높은 벽이 되었습니다."

## 장면 2 — 솔루션 소개 (0:25 ~ 0:35)

**[화면]** 앱 홈 화면 (🧑‍🦳 AI 손주)

**[내레이션]**
"그래서 만들었습니다. 손주가 옆에서 알려주듯 다정한 AI 도우미, **AI 손주**입니다.
설치도, 회원가입도 필요 없이 폰 브라우저에서 바로 씁니다."

## 장면 3 — 기능 1: 서류 풀이 시연 (0:35 ~ 1:10)

**[화면]** 실제 시연 녹화:
1. "어려운 서류 풀이" 누르기 → 계약서 촬영
2. 결과 화면 스크롤: 쉬운 말 요약 → ⚠️ 조심하세요 카드 강조
3. 🔊 버튼 눌러 음성 낭독 소리 들려주기

**[내레이션]**
"계약서를 사진 한 장 찍으면, AI가 초등학생도 이해할 수 있는 쉬운 말로 바꿔줍니다.
특히 위약금이나 자동 갱신처럼 **돈이 나갈 수 있는 조항은 '조심하세요'라고 따로 경고**합니다.
눈이 침침하셔도 괜찮습니다. 버튼 하나면 전부 소리로 읽어드립니다."

## 장면 4 — 기능 2: 화면 인식 튜토리얼 시연 (1:10 ~ 1:45)

**[화면]** 실제 시연 녹화:
1. "폰 사용법 알려줘" → 🎤 눌러서 음성으로 "글자를 크게 하고 싶어요"
2. 설정 화면 캡처 업로드 → "알려줘!" 누르기
3. **캡처 위에 빨간 원 + 👆 "여기를 누르세요" 뜨는 순간 클로즈업** (핵심 장면!)
4. 단계별 안내 목록 보여주기

**[내레이션]**
"말로 물어보세요. '글자를 크게 하고 싶어요.'
지금 보고 있는 화면을 보여주면, AI가 화면을 직접 알아보고
**정확히 어디를 눌러야 하는지 손가락으로 짚어줍니다.**
말로만 하는 설명이 아니라, 내 폰 화면 그대로 알려주니 헤맬 일이 없습니다."

## 장면 5 — 마무리 (1:45 ~ 2:00)

**[화면]** 홈 화면 + 기술 요약 자막 (Gemini API 무료 · 서버리스 · 운영비 0원)

**[내레이션]**
"무료 AI와 웹 기술만으로 만들어 운영비는 0원.
복지관, 경로당 어디서든 QR코드 하나로 보급할 수 있습니다.
모든 어르신 곁에 다정한 손주 하나씩. **AI 손주**였습니다."

## 촬영 팁
- 폰 화면 녹화: 안드로이드 빠른설정의 "화면 녹화" 사용
- 장면 4의 "여기를 누르세요" 마커 등장 장면이 이 앱의 하이라이트 — 2~3초 확대 유지
- 내레이션은 폰 녹음으로 충분, 배경음악은 유튜브 오디오 라이브러리(무료) 활용
