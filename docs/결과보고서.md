## 1. 문제 정의

### 1-1. 고령층이 겪는 디지털 소외의 두 얼굴

**① 어려운 문서의 장벽**
휴대폰 개통 계약서, 보험 약관, 관공서 고지서는 전문용어와 작은 글씨로 가득합니다.
내용을 이해하지 못한 채 서명하는 고령층은 불리한 조항(위약금, 자동 갱신, 유료 부가서비스)의
피해에 그대로 노출됩니다. 주변에 물어볼 사람이 없으면 "그냥 시키는 대로 서명"하게 됩니다.

**② 스마트폰 사용의 장벽**
"글자를 크게 하고 싶은데 어디를 눌러야 할지 모르겠다", "손주에게 또 물어보기 미안하다" —
고령층에게 스마트폰 설정과 앱 사용은 매번 넘어야 할 산입니다. 검색을 해도 검색 결과 자체가
어렵고, 내 폰 화면과 설명 화면이 달라 따라 하기 어렵습니다.

### 1-2. 핵심 인사이트
고령층에게 필요한 것은 **"옆에서 손주가 알려주는 경험"**입니다.
- 문서를 보여주면 → 쉬운 말로 풀어서 설명해주고
- 폰 화면을 보여주면 → **"여기를 누르세요"** 하고 손가락으로 짚어주는 것.

## 2. 솔루션 개요

**AI 손주**는 설치 없이 폰 브라우저에서 바로 쓰는 웹앱으로, 두 가지 핵심 기능을 제공합니다.

### 기능 1 — 📄 어려운 서류 풀이
1. 계약서/고지서를 카메라로 촬영
2. Gemini 멀티모달 AI가 문서를 읽고 분석
3. 결과 제공:
   - **쉬운 말 요약** (3~4문장, 전문용어 금지)
   - **⚠️ 조심하세요**: 위약금·자동갱신 등 불리한 조항 자동 탐지
   - **✅ 꼭 알아두세요**: 금액, 날짜, 기간, 연락처
   - **📖 어려운 말 풀이**: 문서 속 전문용어 사전
4. 🔊 전체 내용 음성 낭독 + 추가 질문(음성 가능)

### 기능 2 — 📱 폰 사용법 알려줘 (화면 인식 튜토리얼)
1. 궁금한 것을 말이나 글로 질문 ("카카오톡으로 사진 보내는 법")
2. (선택) 현재 폰 화면 캡처 업로드
3. AI가 **화면을 직접 인식**하여:
   - 지금 화면에서 눌러야 할 버튼 위치를 좌표로 찾아냄
   - 화면 캡처 위에 **스포트라이트 + 빨간 원 + 👆 "여기를 누르세요"** 표시
   - 이후 단계를 순서대로 쉬운 말로 안내
4. 🔊 모든 안내 음성 낭독

### 접근성 설계 (고령층 UX 원칙)
| 원칙 | 구현 |
|---|---|
| 잘 보이게 | 기본 20px+ 큰 글씨, 3단계 크기 조절, 고대비 색상 |
| 잘 눌리게 | 최소 56px 터치 영역, 화면당 버튼 최소화 |
| 눈이 침침해도 | 모든 결과 TTS 음성 낭독 |
| 타자가 어려워도 | 음성 입력(STT), 예시 질문 버튼 |
| 헤매지 않게 | 화면당 한 가지 일, 항상 보이는 "← 처음으로" 버튼 |
| 다정하게 | 손주 컨셉의 존댓말 화법 |

## 3. 기술 구현

### 3-1. 아키텍처
```
[폰 브라우저 (PWA-ready 웹앱)]
  ├─ 카메라/앨범 → Canvas 리사이즈(1280px) → base64
  ├─ Gemini API (무료 등급) 직접 호출 ── 서버 없음
  │    ├─ 문서 분석: JSON 구조화 출력 (요약/경고/용어)
  │    └─ 화면 인식: box_2d 좌표(0~1000 정규화) 출력
  ├─ Canvas 오버레이: 스포트라이트 + 마커 렌더링
  └─ Web Speech API: TTS(낭독)/STT(음성 질문)
```

### 3-2. 핵심 기술 포인트
- **Gemini 멀티모달 + 구조화 출력**: `responseMimeType: application/json`으로
  요약·경고·용어를 안정적으로 파싱. 무료 모델 3종(2.5-flash → 2.0-flash → 1.5-flash) 자동 폴백.
- **화면 인식 좌표 추출**: Gemini의 bounding box 능력을 활용, 눌러야 할 UI 요소의
  `[ymin, xmin, ymax, xmax]` 좌표를 받아 Canvas에 시각화. 주변을 어둡게 하고 대상만
  밝히는 스포트라이트 효과로 어르신의 시선을 정확히 유도.
- **서버리스 & 프라이버시**: 모든 처리가 사용자 기기 ↔ Google API 간 직접 통신.
  계약서 같은 민감한 문서가 제3의 서버에 저장되지 않음. API 키도 기기(localStorage)에만 저장.
- **저비용 지속가능성**: Gemini 무료 등급 + 정적 호스팅(GitHub Pages) = **운영비 0원**.
  복지관·경로당 등에서 QR코드 하나로 즉시 보급 가능.

### 3-3. 사용 기술
HTML/CSS/JavaScript (Vanilla, 무빌드), Google Gemini API (free tier),
Web Speech API (TTS/STT), Canvas 2D API

## 4. 기대 효과

1. **금전 피해 예방**: 불리한 계약 조항을 서명 전에 쉬운 말로 경고 → 고령층 대상
   불완전판매·과잉가입 피해 감소
2. **디지털 자립**: "여기를 누르세요" 시각 안내로 반복 학습 → 자녀에게 묻지 않고
   스스로 해결하는 경험 축적
3. **보급 용이성**: 설치·회원가입 없는 웹앱이라 복지관 스마트폰 교육 현장에서
   QR 한 번으로 배포 가능, 운영비 0원
4. **확장성**: 다문화 가정 언어장벽(주제 2)에도 동일 구조로 확장 가능 —
   출력 언어만 바꾸면 다국어 서류 번역 도우미가 됨

## 5. 한계 및 향후 계획

- **현재**: 화면 캡처를 수동으로 올려야 함 → **향후**: Android 접근성 서비스(AccessibilityService)
  기반 네이티브 앱으로 확장, 실시간 화면 위 오버레이 안내 ("따라하기 모드")
- 사투리·발화 인식률 개선(고령층 음성 데이터 파인튜닝), 자주 쓰는 질문 오프라인 캐시
- 복지관 파일럿 테스트를 통한 실사용 피드백 반영

## 6. 실행 방법 (심사위원용)

1. https://aistudio.google.com/apikey 에서 무료 API 키 발급 (구글 로그인만 필요)
2. 소스코드 폴더에서 `python3 -m http.server 8000` 실행 후 브라우저 접속
   (또는 GitHub Pages 배포 주소 접속)
3. 첫 화면 설정창에 API 키 입력 → 바로 사용 가능
